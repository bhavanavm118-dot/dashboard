E-Commerce Sales Dashboard – Power BI Project
📌 Project Overview

This project focuses on analyzing an E-commerce sales dataset obtained from Kaggle and building an interactive Power BI dashboard to evaluate business performance. The dashboard provides insights into sales trends, profitability, regional performance, and product-level contribution.

🎯 Objective

The objective of this project is to clean and analyze sales data, calculate key performance indicators (KPIs), and create a visually interactive dashboard that supports data-driven business decisions.

📁 Dataset

Source: Kaggle

Format: CSV

Table Name: ecommerce_sales_data

Key Columns:

Order Date

Region

Category

Product Name

Sales

Profit

Quantity

🧹 Data Cleaning

Data cleaning was performed in Microsoft Excel before importing into Power BI:

Removed duplicate records

Handled missing values in numeric and text columns

Corrected data types (Date, Numeric, Whole Number)

Ensured data consistency for accurate analysis

📊 KPIs Calculated (Using DAX)

Total Sales

Total Profit

Profit Margin (%)

Total Quantity Sold

Average Order Value (AOV)

📈 Dashboard Features

The Power BI dashboard includes:

KPI Cards (Sales, Profit, Profit Margin)

Bar Chart – Sales by Region

Line Chart – Monthly Sales Trend

Bar Chart – Profit by Product Category

Table – Top 5 Products by Sales

Slicers – Region, Category, and Date

The dashboard is fully interactive and allows dynamic filtering.

🔍 Key Insights

Certain regions contribute significantly higher revenue, indicating strong market demand.

Some product categories generate higher profit margins compared to others.

Monthly sales trends show seasonal variations in customer purchasing behavior.

💡 Business Recommendations

Focus marketing efforts on high-margin product categories and high-performing regions.

Align inventory and promotional strategies with seasonal sales peaks to maximize revenue.

🛠 Tools Used

Microsoft Excel (Data Cleaning)

Power BI (Dashboard & Visualization)

DAX (KPI Calculations)

📌 Conclusion

This project demonstrates the end-to-end data analytics workflow including data cleaning, KPI development, visualization, and business insight generation using Power BI.
